Portfolio Live Build & Review

This project documents the live build and external review of my personal portfolio as part of the FlyRank AI Internship.

Overview

The goal of this assignment was to move my portfolio from a work-in-progress into a publicly accessible website containing my actual projects, skills, visual identity, and professional information.

The portfolio was built using Framer with AI used as a build and learning partner where needed.

What Was Completed
Built and published the portfolio publicly.
Added my actual projects, skills, and professional information.

Shared the live portfolio with a real person for external feedback.
Documented the feedback and identified areas that still need improvement.
External Feedback

A real reviewer found the portfolio:

Clean, modern, and personal.
More polished than a typical student assignment.
Strong visually, with an estimated 8/10 design quality.

The reviewer also identified areas that could improve the portfolio's professional impact:

My exact career direction could be clearer.
Projects need stronger case studies and proof of what I actually built.
Project descriptions should explain my role, technologies, implementation, and results.
Some wording could be more personal and less template-like.
My current AI internship experience should be reflected in the portfolio.

The reviewer estimated the current professional impact at approximately 6–7/10, mainly because the portfolio has more evidence to show than it currently communicates.

Still Ugly List

The portfolio is live, but it is not considered finished.

Current improvement areas:

Clarify my professional direction.
Strengthen project case studies.
Add more evidence of implementation and results.
Make the copy more personal.
Update the portfolio with my current AI internship experience.
Improve how my projects demonstrate my actual technical skills.
What I Learned

Publishing the portfolio made it possible to receive feedback from someone outside the build process. The biggest lesson was that a visually strong portfolio is not enough; it also needs clear positioning and strong evidence of what I can actually build.

The next iteration will focus less on visual polishing and more on proof, project depth, and clearer professional positioning.
